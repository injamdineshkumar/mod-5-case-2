# Spam vs Non-Spam Message Classifier

## Description
A machine learning project that detects spam
and non-spam SMS messages.

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn

## Machine Learning Techniques
- TF-IDF
- Chi-square feature selection
- Multinomial Naive Bayes

## Features
- SMS dataset upload
- Model training
- Accuracy evaluation
- Confusion matrix
- Message prediction

## Installation
pip install -r requirements.txt

## Run Application
streamlit run app.py
